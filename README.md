# NoteForge

Автономный ИИ-агент для автоматического решения и исправления кода в Jupyter Notebook.

## Принцип работы
- Использует Jupyter KernelManager для запуска и выполнения ячеек в реальном времени.
- Интегрируется с API Gemini (GeminiClient) для генерации кода и предложений по исправлению ошибок.
- Автоматически перехватывает ошибки выполнения (traceback), отправляет их LLM для анализа и применяет предложенные исправления (ICodeFixer).
